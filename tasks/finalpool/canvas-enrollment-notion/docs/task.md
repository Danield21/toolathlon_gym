The university registrar's office needs a comprehensive enrollment overview across all courses in the learning management system. Please retrieve the list of all courses and then count the number of students enrolled in each course. A student enrollment is identified by the enrollment type "StudentEnrollment".

After collecting the student counts, create a database in the project management workspace titled "Course Enrollment Tracker" to serve as a centralized tracking board. Each course should have its own entry in this database. Each entry's title must be the course name exactly as it appears in the learning management system (you may append extra identifiers such as term codes, but the full course name must remain intact in the title). Each entry should have the course name as the title and an additional property Student_Count holding the number of students enrolled in that course.

Finally, send an email to admin@university.example.com with the subject "Course Enrollment Summary Report". The body of the email should include the total number of courses, the overall total student enrollment across all courses (the sum of every course's Student_Count), and a brief listing of the top five courses by student enrollment showing each course name and its student enrollment count.
