Start by fetching the event details from http://localhost:30234/api/event_details.json. This file contains the event name, date, guest count, per-person budget, dietary restriction breakdown, and required courses. Record all the details carefully as they will drive the menu planning.

Next, read the Dietary_Guidelines.pdf file in the workspace. This document describes how to handle various dietary restrictions when planning menus, including substitution strategies and cross-contamination prevention. Note the key guidelines for vegetarian, gluten-free, and nut allergy accommodations.

Then browse the recipe database to find suitable recipes for each required course. You need recipes for appetizer, main course, and dessert. For each course, select at least two recipe options: one standard option and one that accommodates the dietary restrictions (vegetarian and gluten-free). Consider the cost implications and whether the recipe can be scaled up to serve 50 guests.

Also review the vendor contacts file in the workspace for the email addresses of the catering coordinator and the supplies vendor.

Create an Excel workbook called Event_Menu.xlsx in the workspace with four sheets. The first sheet should be named "Menu Plan" with columns Course, Recipe_Name, Serves, Cost_Per_Person, and Dietary_Tags. Recipe names should be in English. In the Course column, use the course names from the event details (appetizer, main, dessert). In the Serves column, enter 50 for every recipe row, since all recipes are scaled to serve the full event of 50 guests. Dietary_Tags should indicate which restrictions each recipe accommodates using the full words Vegetarian, Gluten-Free, or Nut-Free (separated by commas). Include at least two options per course. The second sheet should be named "Ingredient List" with columns Ingredient, Quantity_For_50, Unit, and Estimated_Cost. List all ingredients needed across the menu scaled for 50 guests. The third sheet should be named "Cost Summary" with columns Item and Amount, including Total_Food_Cost, Cost_Per_Person, Budget_Per_Person, Budget_Variance (budget minus actual, i.e. Budget_Per_Person minus Cost_Per_Person), and Service_Fee_Estimate (15% of Total_Food_Cost). The fourth sheet should be named "Dietary Accommodations" with columns Restriction, Guest_Count, Menu_Options, and Notes. For each dietary restriction from the event details, list the number of affected guests, which menu items they can eat, and any special preparation notes.

Important formatting rule: In the Cost Summary sheet, enter every Amount as a plain literal number (for example 1050 or 157.5). Do not use Excel formulas such as =B4-B3 or =0.15*B2 — write the computed numeric values directly.

After creating the Excel file, send an email to the catering coordinator at catering@vendor.com with the subject "Menu Plan for Annual Company Dinner".
