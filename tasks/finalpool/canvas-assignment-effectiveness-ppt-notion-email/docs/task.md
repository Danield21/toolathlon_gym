## Computation conventions (follow these exactly)

- **Scores are percentages on a 0-100 scale.** Use the raw percentage scores as they appear in the LMS. When computing the Discrimination Index, do NOT rescale or normalize scores to points_possible -- use the formula exactly as written in the PDF: `DI = (top_27%_avg - bottom_27%_avg) / points_possible`.
- **Enrolled students** for a course = the number of unique students who have at least one graded submission in that course (this is also the denominator for Completion Rate).
- **Top/bottom 27%**: rank all enrolled students of a course by their overall course average (mean of all their graded assignment scores, lowest to highest). Take the top 27% = the highest-scoring `floor(0.27 * N)` students and the bottom 27% = the lowest-scoring `floor(0.27 * N)` students, where N is the number of enrolled students (round the group size down). When two students tie, break ties by student ID (ascending).
- **Only include graded submissions** (workflow_state = graded) with a non-null score.
- **Score_Std_Dev** is the population standard deviation of the scores for that assignment.
- Write every numeric value into the Excel file as a **literal number** (e.g., `2.536`). Do NOT write Excel formulas (such as `=AVERAGE(...)` or `=B2/C2`) -- the file must contain the computed values themselves.
