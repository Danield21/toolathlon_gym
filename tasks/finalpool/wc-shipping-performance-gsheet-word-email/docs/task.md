You are a logistics analyst responsible for monthly shipping performance reporting. Analyze WooCommerce shipping data and produce a performance dashboard and report.

First, retrieve orders from the WooCommerce store (include completed, processing, on-hold, and pending orders). Analyze each order's shipping method. Group orders by shipping method (Standard Shipping, Express Shipping, and orders with no shipping charge), and for each group calculate the total number of orders, the total revenue, and the average order value.

Next, create a Google Sheet titled "Shipping Performance Dashboard" with the following columns (use these exact literal header strings, do not translate or paraphrase): Zone_Name, Order_Count, Total_Revenue, Avg_Order_Value. Populate it with one row per shipping method group. Map the shipping methods exactly as follows: orders whose shipping_lines method_title contains "flat rate" or matches the flat-rate standard shipping line must appear as Zone_Name "Standard Shipping"; orders whose shipping_lines method_title contains "express" must appear as Zone_Name "Express Shipping"; orders with no shipping line (empty or null shipping_lines array) must appear as Zone_Name "Free Shipping". Use these three exact label strings ("Standard Shipping", "Express Shipping", "Free Shipping") in the Zone_Name column - do not use alternative names like "Flat Rate" or "None". Round monetary values to 2 decimal places.

Then, create a Word document called Shipping_Performance_Report.docx in the workspace. The document must include: a heading "Shipping Performance Report", an executive summary paragraph explaining the overall shipping performance, a table whose header row uses the exact same literal column labels as the Google Sheet (Zone_Name, Order_Count, Total_Revenue, Avg_Order_Value - no translation or rewording), and at least one more paragraph with analysis or recommendations. Use the same three Zone_Name values in the Word table as in the Google Sheet. The document must have at least 3 paragraphs total.

Finally, send an email to logistics@store.example.com from operations@store.example.com with the subject "Monthly Shipping Performance Report". The email body should summarize the key shipping metrics.

Refer to the Shipping_Strategy.pdf file in your workspace for context on shipping policies.
